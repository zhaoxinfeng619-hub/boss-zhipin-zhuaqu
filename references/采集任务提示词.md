# BOSS 直聘岗位采集 · 可复用提示词

> 用途：下次要做同类采集时，直接复制下面的提示词发给我即可。只需替换 `{}` 里的内容。

---

## 一、标准版（直接复制这段）

```
按 {表头文件路径} 的表头，采集 {城市} 的「{关键词}」岗位。

要求：
1. 只用浏览器操作（computer use）的方式，禁止调用任何接口（比如 /wapi/ 下的
   joblist.json）来取数据。走 boss-zhipin-scraper 技能里已沉淀的流程和脚本。
2. 需要登录时你生成二维码给我扫，不要弹窗口影响我用电脑，浏览器用后台无窗口模式跑。
3. 目标 {N} 条；先跑 {先跑条数}，我看过没问题再继续加到 {N} 条。
4. 排除实习岗位；排除猎头 / 外包帖。
5. 最后交付一个单文件 CSV（原地累加，不要新建别的文件），文件名
   {输出文件名}，编码 UTF-8-SIG，列顺序严格按表头文件，岗位链接不能重复。
6. 如果候选池不够，自己换关键词和筛选条件去扩池，不许用接口补数据。
```

**填入示例**（就是这次实际跑的那次）：

| 占位符 | 值 |
|---|---|
| `{表头文件路径}` | `~/Downloads/boss表头.csv` |
| `{城市}` | 北京 |
| `{关键词}` | AI产品经理 |
| `{N}` | 200 |
| `{先跑条数}` | 先来 10 条（累计到 20 再看） |
| `{输出文件名}` | `boss_AI产品经理_北京.csv` |

## 二、精简版（表头已经固定时用这个，最省事）

```
用 boss-zhipin-scraper 技能，按 {文件路径} 的表头跑 {城市}「{关键词}」岗位，
只要浏览器方式不要接口，{N} 条，排除实习和猎头，原地累加到 {输出文件名}，
登录二维码发我扫。
```

## 三、可以调的参数

| 想改什么 | 怎么改 |
|---|---|
| 换城市 | 改 `{城市}`。技能里已记了城市码：北京 101010100 / 上海 101020100 / 深圳 101280600 / 广州 101280100 / 杭州 101210100 |
| 换岗位方向 | 改 `{关键词}`。技能会自动用「语义同族多关键词 × 筛选组合」扩池（比如 AI产品经理 会扩成 AI产品 / 大模型产品经理 / AIGC产品经理 / Agent产品经理 / 智能产品经理） |
| 换表头 | 只改 `{表头文件路径}`，列的顺序和名称以该文件为准 |
| 追加条数 | 直接说「继续跑 N 条」，我会读现有 CSV 建链接黑名单后增量追加，不会重复 |
| 放宽/收紧口径 | 额外说明一句，例如「不限行业，AI 产品经理大类都算」「运营岗也算」「不要校招岗」 |
| 想先验收再放量 | 用「先跑 10 条，我看过再继续」的分批说法 |

## 四、这次踩过、下次会自动绕开的坑

这些已经写进技能，不用你在提示词里重复交代：

- **薪资数字被私用区码点混淆**（真实数字 = 码点 − 0xE031）→ 自动解码
- **JD / 标签里插了 `visibility:hidden` 噪声 span**（`boss`、`来自BOSS直聘`）→ 用容器级 `innerText` 过滤
- **列表页 `page=N` 参数无效**，恒返回同一批 15 条 → 靠筛选条件 + 换关键词扩池，不靠翻页
- **单关键词池子会封顶**（约 325 条唯一职位）→ 要更多必须换关键词
- **猎头帖只能在详情页识别** → 靠 `招聘者` 字段含「猎头」+ 匿名「某…公司」判断
- **批量浏览器操作必须落成 `.sh` 脚本后台跑**，内联循环会被杀掉

---

## 五、需要你知道的前提

- 登录要靠你**扫码**，二维码 1–2 分钟就过期，我发出来你要马上扫。
- 采集全靠本机 Chrome 后台跑，**不占用你的屏幕**，但会持续十几分钟到半小时（200 条约 32 分钟），期间你可以正常用电脑。
- 只在你自己已登录的账号下采公开职位信息，控制频率。
